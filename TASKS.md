# TASKS.md

10 маленьких безопасных задач для проекта Kidan Shop. Выполнять по очереди, без пуша и деплоя без подтверждения владельца.

## Контекст проекта

- Проект — статический магазин/маркетплейс на HTML/CSS/JS с Vercel serverless API в `api/`.
- Основные файлы: `index.html`, `profile.html`, `script.js`, `style.css`.
- API: `api/create-checkout-session.js`, `api/stripe-webhook.js`, `api/support.js`, `api/support-admin.js`, `api/security-utils.js`.
- Конфиги/доки: `package.json`, `vercel.json`, `.env.example`, `DEPLOYMENT.md`, `STRIPE_SETUP.md`, `SUPPORT_ADMIN_SETUP.md`, `AGENTS.md`.
- Доступные проверки из `package.json`: `npm run check`, `npm run build`.

## Общие правила выполнения

- Перед каждой задачей кратко написать план и затрагиваемые файлы.
- Делать одну задачу за раз.
- Не менять `.env` и не добавлять секреты.
- Не удалять существующий функционал.
- После изменений запускать проверки, указанные в задаче.
- Если задача блокируется, записать проблему и контекст в `AGENT_NOTES.md`.
